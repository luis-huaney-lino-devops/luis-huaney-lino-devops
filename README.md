## Sobre mí

**Ingeniero de Sistemas e Informática titulado** por la [UNASAM](https://www.unasam.edu.pe/), con **más de 4 años** construyendo software de extremo a extremo para **banca regulada, retail y sector público** en el Perú.

Hoy desarrollo y migro los sistemas internos de **Promart Homecenter** hacia una arquitectura mantenible, incorporando componentes de **IA aplicada** para automatizar tareas que antes se resolvían a mano. Antes lideré el diseño y desarrollo del **Sistema de Ingresos, RR. HH. y Selección de Personal de Caja Arequipa** sobre la plataforma corporativa Caja 360, modelando la persistencia en SQL Server y Oracle.

No me quedo en una capa: **modelo la base de datos, escribo el servicio, pinto la pantalla y la pongo en producción.** Es lo que evita que una función se quede a medias entre dos equipos.
